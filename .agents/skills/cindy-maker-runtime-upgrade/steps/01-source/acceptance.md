# 01 验收

- [ ] 两仓、旧/目标 Runtime、插件版本、本次分支、已有修改与授权范围已明确。
- [ ] 区分主包版本、Maker 源码/包/bundle 版本、当前运行版本；差异有解释。
- [ ] 优先检查本地产物/缓存；未为此安装全局 CLI、清缓存或改其他 Agent MCP。
- [ ] 原始包可追溯到官方发布物或已记录的本地构建；本地构建没有冒充正式包。
- [ ] 需要编译时已实际成功，构建日志/版本/锁文件/纳入改动/产物哈希一致；现有产物得到保护。
- [ ] tgz 在解包前校验路径和类型；旧 vendor、旧原始包、新原始包分开保存，可回溯比较。
- [ ] 新旧文件与行为差异摘要已写入本次记录，下一步能拿到精确候选包。

缺原始包或来源不明时，本步未通过，先补输入；可以继续只读调查，不能先覆盖 vendor。
通过后只携带来源摘要、候选路径、差异索引到 [02 操作](../02-compatibility/run.md)。
