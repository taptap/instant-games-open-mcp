# Maker Canvas：共享画布

本包维护本地 Maker MCP 与 Maker Web 共用的画布页面、编辑规则和业务交互。
共享源码以本包为准；两端分别接入自己的项目、素材、存储和服务。
本包保持 private，不单独发布 npm。Web 可通过生成脚本导入产物，保留来源版本，更新时重新生成。

## 按任务阅读

共享画布文档都在本目录内。先看本页，再按任务选择对应文档的章节，不需要每次通读全部文档。

| 要做什么                                               | 阅读入口                                         |
| ------------------------------------------------------ | ------------------------------------------------ |
| 接入本地或 Web、修改素材读写、保存恢复、服务调用或构建 | [本地与Web接入](docs/本地与Web接入.md)           |
| 修改模板、图片引用、识图拆分、动画精灵或自动化操作     | [画布功能与业务规则](docs/画布功能与业务规则.md) |
| 修改 Web 的菜单、导入、生成面板、连线和视频交互        | [Web画布交互差异](docs/Web画布交互差异.md)       |

文档说明业务语义和接入约定；完整字段以类型定义为准，样式数值以源码为准。
本地或 Web 自身的部署、认证配置和操作手册由各自宿主维护，不是理解本包的前置阅读。

## 代码如何分工

```text
本地宿主 ─┐
          ├─ getCanvasPageHtml({ hostScript, themeScript }) ─ 共享页面与控制器
Web 宿主 ─┘                                                └─ Host / Store
```

| 层                 | 负责什么                                           | 不负责什么                    |
| ------------------ | -------------------------------------------------- | ----------------------------- |
| contracts / domain | 文档契约、编辑、引用关系、素材与流程规则           | DOM、Node、实际文件与网络访问 |
| browser            | 页面、交互、模板库、浏览器媒体处理与编码           | 推测项目目录、凭证与远端权限  |
| 本地 / Web 宿主    | 项目绑定、授权、素材读写、保存、服务请求与结果交付 | 维护另一份共享编辑逻辑        |

素材引用与访问 URL 分开：共享层处理引用和内容，宿主解释引用、校验访问并决定读写位置。
本地与 Web 不必使用相同目录；导入导出以目标端实际返回的引用或交付状态为准。

## 修改与协作

1. **按职责修改。** 公共规则在共享层维护，平台差异在宿主或已有外观适配中处理。
   接口只增加当前需求需要的能力，允许必要的跨模块调整，不预建通用扩展框架。
2. **核对直接调用方。** 改字段、参数范围或默认行为时检查两端实际消费位置，说明是否需要同步。
   两端可以分阶段接入，不要求每次同步发布，也不以一端暂未接入限制另一端能力。
3. **保护已有数据与任务。** 保留草稿、引用和各端已有的项目隔离与保存保护；
   失败或未知结果沿原恢复链处理，不盲目重提付费任务。具体约定见接入文档。
4. **验证与风险相称。** 检查受影响的直接链路，说明实际验证结果和未验证部分；
   不把类型检查或构建成功写成真实运行验收通过。
5. **文档按主题维护。** README 保持入口与职责说明，细节更新到对应包内文档；
   不重复记录容易从源码确定的数值，不把临时调查或验收记录追加成长久规范。

模板与 UI 工作流按实际能力接入。`features.uiEditor` 目前控制画布导出后的交接入口，
并不代表本地 UI 编辑器已经包含在共享包中；扩展时按真实依赖抽取可复用部分。

## 构建与检查

开发共享包时，在源码仓库根目录使用现有命令：

```sh
npm run maker:canvas:build
npm run maker:canvas:check
```

仅改文档时检查内容、链接和差异，不运行构建或代码测试。
产物消费、浏览器兼容与运行验证见[本地与Web接入](docs/本地与Web接入.md#构建与验证)。
