# Web画布交互差异

[返回共享画布入口](../README.md)

修改 Web 画布的菜单、导入、生成面板、连线或媒体交互时阅读。
本页描述 `host.appearance: 'web'` 下的现有行为，不是 Web 永久的功能范围限制。
共享业务语义见[画布功能与业务规则](画布功能与业务规则.md)，服务接入见[本地与Web接入](本地与Web接入.md)。

按需定位：[外观](#外观与入口)、[图片与连线](#图片卡与连线)、[生成面板](#生成面板)、
[导入](#上传拖放与粘贴)、[图片处理](#图片处理与下载)、[视频](#视频与序列帧)、[分组](#分组与标注)。

## 外观与入口

`appearance` 未设置或为 `'default'` 时保持本地默认外观；`'web'` 为页面添加
`canvas-appearance-web`，使用 Web 样式与交互适配。外观选项不替代平台身份、服务能力或权限校验。
本页明确列出行为差异；基础连线校验、撤销与保存仍复用共享控制器。

颜色使用 `--canvas-*`，Web 由 `--maker-*` 映射，随 `:root[data-theme]` 切换明暗。
尺寸、色值、阴影和动画时长以源码为准，不在文档维护第二份数值表。

| 源码                                              | 修改内容                                   |
| ------------------------------------------------- | ------------------------------------------ |
| [webStyles.ts](../src/browser/webStyles.ts)       | Web 样式、主题与对话框外观                 |
| [webChrome.ts](../src/browser/webChrome.ts)       | 卡片连接点、菜单、提示、视频控件等交互适配 |
| [generationUi.ts](../src/browser/generationUi.ts) | 图片和视频生成面板                         |
| [page.ts](../src/browser/page.ts)                 | 页面装配、导入、快捷键及控制器接线         |

- 页签栏的关闭按钮在悬停或激活时显示，重命名按钮在激活页签悬停时显示；键盘聚焦仍可访问。
  新建画布在最后一个页签后，“全部画布”在右侧。
- 宿主可通过 `getWorkspaceState` / `setWorkspaceState` 保存已打开页签顺序与激活项；
  启动时按已授权的画布列表过滤失效 ID，仅加载激活画布，其余页签按需读取。
  切换时立即显示目标名称与加载提示，完成或失败后解除等待；保存与离开保护沿用原链路。
- 工具条选择/拖拽状态跟随实际模式，包括空格临时平移；保存图标通过 `data-save-state`
  表达 saved / unsaved / saving / failed，并提供提示。
- 默认自动区分滚轮与触摸板：离散滚轮以光标为中心缩放，平滑双指及惯性事件平移；
  捏合或 Ctrl/⌘+滚轮缩放，Shift+滚轮平移。浏览器不提供可靠的设备身份，误判时可在
  “更多画布操作 → 滚轮与触摸板”固定输入模式；Web 宿主按本机用户和项目记住偏好。
- 运行日志记录图片、视频的生成开始、生成完成、回填保存及导入文件名。生成完成不代表
  已回填；异步消息按原画布归档。宿主可提供本机持久化，切换、刷新后恢复最近 200 条，
  “清空记录”只清除当前画布日志，不影响项目内容或远端生成任务。
- 自定义图标提示替代原生 title，支持悬停与键盘聚焦，保留 `aria-label`；
  Esc、滚动或失焦会隐藏提示。旧内核通过输入方式标记模拟键盘焦点环，不依赖 `:focus-visible`。
- 单选下拉保留原生 `select` 作为值来源，自定义浮层选择后触发 `input` / `change`；
  支持键盘打开和选择，Esc、Tab、点外部、滚动或缩放关闭。
- 画板点阵同时适配明暗模式。“适配画布”避开工具条和显示中的流程条，按卡片实际尺寸计算；
  默认外观同样避开工具条。
- 关闭的能力不显示对应入口。模板关闭时无“编辑视频”等模板入口；资源导出关闭时隐藏相关菜单，
  图片下载和视频历史下载仍按各自入口提供。入口隐藏不等同于禁用自动化命令。

## 图片卡与连线

- 侧边“+”仅在单选或键盘聚焦时显示。普通导入图片只有右侧，图片槽及 AI 结果卡两侧都有。
  拖线会预览和吸附，松手仍走共享 `connect` 校验。
- 四角缩放固定对角并保持图片比例，走撤销栈；多选不显示缩放角柄或整组选框。
- 连线画成无箭头曲线，悬停或选中有流光与剪断入口；重绘不重启动画，减少动态效果时静止。
  只有 `image-variant` / `first-frame` 可剪断或按 Delete 删除，其余派生连线只展示状态。
- 删除指向已有图片的引用线时，移除该来源 `sourceSnapshot(s)`，不设置 `templatePending`，
  不使下游失效，保留图片。默认外观仍按原规则把分组成员标为待处理。
- 删除空槽入线时，两种外观都清理下一次生成的草稿来源。Web 中非模板分组的 AI 结果卡断线后
  设置 `referenceInput: {includeSelf:false}`，只使用剩余入线，不回退到旧生成来源；撤销恢复原行为。
- 点击空图片槽只选中并打开生成面板；上传由单选空槽上的“上传”按钮触发，键盘仍可操作。
  生成中的槽和已填图片不显示该上传按钮。
- AI 结果卡选中后打开生成面板，包括 Agent 经 `fill-slot` / `replace-image` / 带 prompt 的
  `import` 放入的结果。再次生成原位回填，保留 id、位置、宽度、标题与连线，高度按新比例调整；
  旧图保留在撤销栈和素材文件中。
- 普通导入图片只显示选中菜单，经快速编辑后新建连线结果卡；默认外观的快速编辑与重新生成
  仍新建“图片变体”结果卡。

## 生成面板

面板优先位于卡片下方，空间不足时翻到上方，并限制在画板可用区域。
拖拽与缩放时保留输入节点和未提交内容，只更新位置，避免重建面板丢失输入。
Web 不显示默认外观中的分辨率说明、无参考图提示以及服务商/服务模型说明。

- 模型、分辨率与比例按选项显示，不由展示文案改变提交值。
- “素材规范”开关记录在 `generationDraft.parameters.assetConstraints`；弹层可编辑约束文本并恢复默认。
  文本保存在 `document.settings.assetConstraintText`，为空或等于默认时省略；仅启用后附加到请求，
  卡片 `generation.prompt` 只保留用户文本。发送或点击外部关闭弹层。
- 输入 `@` 列出面板的输入图片，按发送顺序编号；可按编号或说明筛选，方向键选择，Enter / Tab 确认。
  Esc、空格或离开输入框关闭；选中后插入 `@图N`。
- 对应有效输入图的 `@图N` 显示缩略图标签，发送值仍是原生 textarea 中的文字。
  镜像显示层保持换行与光标位置一致，退格或 Delete 命中标签时整段删除。
- 生成中显示状态遮罩，停止等待按钮始终可点；停止等待不代表取消远端任务。

## 上传、拖放与粘贴

“资产”按钮仅在宿主提供 `toggleAssetPanel` 时显示，按下态由 `setAssetPanelOpen` 同步。
“加入对话”只传已保存路径且不在处理中的选中图片，支持单选与多选；缺少宿主钩子时不显示。

- 空白右键提供新建图片卡片、上传图片；提供 `pickProjectImages` 时显示“从素材库添加”，
  逐张走 `importProjectAsset` 校验，从落点排开，最多 20 个。
- 桌面文件拖放或 ⌘/Ctrl+V 支持 PNG/JPEG/WebP；开启视频功能时也支持 MP4/MOV/WebM。
  图片上限 20 MiB、视频上限 100 MiB，仍受宿主实际上传限制。
- 每个文件建一张卡，从落点排开，最多 20 个；粘贴使用指针位置或视口空位。
  上传期间显示占位状态，失败移除该占位，整次导入为一步撤销。
- 落在空图片/视频槽时原位填充；单选一个空图片槽粘贴图片也直接填槽。
  跨类型填充的清理与撤销规则见[业务规则](画布功能与业务规则.md#图片槽与连线)。
- 宿主的 `application/x-asset` 按项目路径引用，不重新上传；同次拖放附带的浏览器图片文件忽略，
  避免重复上传。宿主不允许直接引用、但 `readSource` 可读的图片（如精灵候选图）上传副本。
- 画布内复制会写入剪贴板标记，随后粘贴复制卡片；系统剪贴板改为文件后粘贴文件。

## 图片处理与下载

选中菜单和右键菜单提供加入对话、抠图、调整抠图、下载及下载 JPG，按宿主钩子和功能开关显示。
资源导出关闭时不重复显示图片“导出资源”组；默认外观保留原组。

### 抠图

`cutout` 开启时，一键抠图自动识别底色并使用 `CANVAS_BACKGROUND_DEFAULTS` 的参数，
在浏览器内处理，不调用生成或付费服务。经 `store.importImage` 保存为新 PNG，
在右侧建立“原标题 · 抠图”卡和 `image-variant` 连线，可撤销。

处理中保护原卡；未识别到底色或处理失败不建结果卡，提示可改用“调整抠图”。
画布容量达到 400 张卡或 800 条线时在导入前拒绝。
“调整抠图”打开单图参数面板，支持取色、容差、边缘过渡、去溢色、处理范围和实时预览；
保存与一键抠图共用提交链路。保存失败保留面板，保存中不可取消。
默认外观的去背景仍使用完整本地图片编辑器流程。

### 裁剪、旋转与翻转

`features.imageTools: true` 时提供裁剪、顺时针旋转 90°、水平和垂直翻转。
都另存项目内新 PNG，保留原文件，每次一步撤销。

裁剪在卡片上拖框、缩放，可选自由或固定比例；完成/Enter 应用，取消/Esc/点空白处放弃，
期间隐藏卡片菜单和生成面板。结果在右侧新建“原标题 · 裁剪”连线卡。
旋转与翻转原位替换，保留 id、位置、宽度、连线和生成信息，高度跟随新比例。

### 下载

下载按钮直接导出 PNG，右键另提供 JPG，经共享编码和 `host.deliverExport` 交付，落点由宿主决定。
Web 使用普通按钮，避免默认外观的 fixed 下载浮层在毛玻璃菜单中被定位容器与 overflow 裁剪。
取消、失败、保存或下载成功的含义见[交付契约](本地与Web接入.md#素材读取与交付)。

## 视频与序列帧

此节在相应 `video` / `sequence` / `sections` 能力开启时生效，不要求同时开启模板或资源导出。

- 视频槽与视频结果使用图片卡式布局；结果缩放保持视频比例，空槽连接的首帧只显示在生成面板参考图行。
  生成、失败、待确认、等待继续状态保留原行为，并适配 Web 展示。
- 图片选中/右键菜单提供“视频生成”，视频结果提供“拆序列帧”；空白右键可导入视频。
  工具条称为“新建视频卡片”“分组”，“视频历史”在更多菜单，日志栏收起。
- 选中空视频槽打开生成面板，参考图标注首帧、尾帧或参考图序号，发送键旁提供视频导入。
- 视频只接受图片输入，没有视频到视频的边，所以视频卡没有侧边“+”。
  已有图片的右侧“+”可选建图片或视频卡片；视频以 `first-frame` 连入，不继承图片参数。
  未开视频功能或图片槽为空时，仍直接新建图片槽；菜单支持方向键、回车和 Esc 返回焦点。
- 视频结果点击只选中，拖动移动卡片，播放/暂停由卡内按钮控制，不使用原生视频控件。
  进度条有跳转、静音和时长显示；悬停、选中、聚焦或播放中才显示，其事件不触发卡片拖拽。
  保留 slider 语义，方向键跳转一秒，Home/End 到首尾；时长为 Infinity 的 WebM 先探测再复位。
- 没有任何输入图时可文生视频，隐藏输入方式选择；比例提供 16:9（默认）、9:16、1:1，
  不提供依赖图片的自适应。连接图片后回到首帧等模式。
- 模型 2.5 不弹共享页面自己的生成确认，费用确认由 Web 宿主负责，页面传 `userConfirmed:false`；
  默认外观保留原确认。不能把入口差异解释为绕过宿主确认。
- 拆序列帧、视频历史与动画卡沿用 Web 面板主题；视频、帧预览和生成面板的复用规则见
  [媒体预览与状态](画布功能与业务规则.md#媒体预览与状态)。
- 视频历史下载经 `deliverExport`，不受 `resourceExport` 开关影响；
  模型参数、任务恢复和回填条件见[视频服务](本地与Web接入.md#视频服务)。

## 分组与标注

标注框中空区域始终穿透到内部卡片和箭头，选中后也不拦截。拖动边线移动整个框，
四个角调整大小；移动保留鼠标落点，不将框中心吸到光标。箭头在线身、箭头头部和
选中后的端点响应操作。

分组标题双击或右键重命名，Enter/失焦保存，Esc 取消，最长 80 字。
“取消分组”只删除分组框，成员保留原位、清除 sectionId 并选中；
“删除分组”连同成员走既有删除保护，两者均可撤销。

标注选中菜单增加删除按钮；默认外观仍只显示颜色。
两种外观的右键删除和 Delete 都走原撤销栈。
