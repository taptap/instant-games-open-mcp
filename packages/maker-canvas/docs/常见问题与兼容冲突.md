# 常见问题与兼容冲突

[返回共享画布入口](../README.md)

本页用于积累本地 Maker MCP 与 Web 共用画布时，实际遇到且有复用价值的冲突与兼容问题。
是否值得记录，由处理问题的开发 AI 结合实际情况判断，不要求每次开发都新增条目。
PR 审核意见、未经验证的风险推演和一次性整理记录不直接收录。

记录时说清影响哪一端、什么场景会触发、实际表现、原因与处理方式，并给出必要的依据。
涉及产品取舍时说明为什么；尚未查明的原因如实标注，不自行补全。
不限定模板，重点是让后续开发理解问题，避免重复踩坑。

修复后更新原条目，保留仍有价值的兼容原因，删除失效的临时绕法；
稳定的接入约定和业务规则维护在对应文档中，这里按需引用。

目前暂无收录条目，后续遇到合适的问题再补充。
