# TapTap Maker MCP 更新记录

这份文档记录独立 `@taptap/maker` 包的用户可见更新。

## 0.0.38

### 新增与优化

- 新增 Git 操作，可查看远端状态、查看差异并提交改动。
- 优化本地 Git 同步和推送；分叉时会尝试合并远端，发生冲突时列出冲突文件并停止推送。

### 修复

- 修复云端未提交改动阻塞推送的问题，包括 `Working directory has unstaged changes` 和 `Could not update working tree to new HEAD`。
- 修复浅克隆拉取时报 `expected 'acknowledgments'` 的问题。

## 0.0.37

### 新增

- 新增创作画布，支持多媒体创作、模板和资源导出。
- 新增可视化 UI 编辑器，支持 Lua UI 提取和 NanoVG。
- 支持独立配置生图模型、识图模型及自定义 API。
- 更新图片模型，新增视频模型和音乐参考素材。
- 接入 Validate Skill，支持验证历史、日志和截图归档。

### 优化

- 减少预览重复下载和复制，支持占用统计及按项目清理缓存。
- 优化日志筛选、Lua 警告和错误堆栈展示。
- 本地开发支持为素材生成 `.meta` 文件。

## 0.0.36

### 新增与优化

- 控制台支持安全拉取远端代码，遇到冲突时提供 AI 处理指引。
- 切换项目时保留当前页签并自动刷新内容。
- 简化本地预览启动，支持 AI 限时运行、获取日志和停止游戏。

### 修复

- 完善 Lua 日志收集，修复预览刷新、取消和进程回收问题。
- 修复控制台 Lua 检查及远端授权失效后的自动恢复。
- 修复 Windows 下意外弹出命令行窗口的问题。

## 0.0.35

### 新增与修复

- 优化控制台远端拉取、项目切换、本地预览和 Lua 日志收集。
- 修复预览刷新、取消、进程回收、Lua 检查及远端授权恢复问题。

## 0.0.34

### 新增

- 新增本地控制台，集中管理项目、构建、测试二维码和日志。
- 支持电脑本地预览，可调整窗口大小和横竖屏方向。
- 支持构建前检查 Lua 代码，并在控制台提交问题反馈。
- 支持下载云端个人 Skills 到本地项目。

### 修复与优化

- 修复部分 Windows 预览启动、资源加载和联机异常。
- 修复预览退出后无法重启及运行状态显示错误的问题。
- 改善中文字体缺失、资源重复引用和提交前远端同步问题。

## 0.0.32

### 修复与优化

- 修复 Windows Node.js 26 环境下的构建超时问题。
- 修复 Windows 更新 Maker MCP 时的文件复制问题。
- 优化视频生成费用确认流程，付费素材工具不再自动重试。
- 优化构建失败诊断、沙盒环境提示和 Maker 文档查询指引。
- 修复 Git HTTP/2 不兼容导致的构建失败。
- 减少缺少证据时的重复问题上报和错误归因。

## 0.0.30

### 新增

- 新增 DeepSeek Harness（DSH）支持，可自动检测并完成 MCP 配置。
- 新增 MCP 问题反馈功能，经用户同意后提交脱敏诊断信息。

### 修复与优化

- 修复多项目共用 MCP 配置时项目路径互相覆盖的问题。
- 优化 Proxy Tools 缺失、连接超时、断线恢复和错误信息展示。
- 优化 Windows、受限沙盒及 npm/npx 不可用场景下的 MCP 安装和启动。

## 0.0.29

### 优化

- 优化音频、音效和角色配音功能。
- MCP 升级不会中断当前会话和已加载工具。
- 优化 Maker 状态查询、远端诊断和构建失败恢复指引。

## 0.0.28

### 修复与优化

- 优化项目连接复用，连续调用工具和构建无需反复连接。
- 优化多项目隔离和断线恢复。
- 修复普通问题反馈被误识别为 Maker 玩家反馈的问题。
- 优化素材工具选择。

## 0.0.27

### 修复与优化

- 修复 Windows 启动器依赖 PATH 导致无法连接的问题，改用可靠的 Node/npm 启动方式。
- MCP 配置写入前自动验证连接和工具可用性，验证失败时保留现有配置。
- 优化多 AI 客户端故障诊断，Cindy 等客户端不再误报 WorkBuddy trust 问题。
- 优化广告接入流程，AI 会优先读取内置广告指南。
- 修复初始化、安装和升级失败时退出状态不准确的问题。

## 0.0.26

### 优化

- 优化 Maker MCP 工具描述和 AI 能力路由。
- 优化测试二维码屏幕方向确认，已有项目自动复用配置。
- 优化项目配置预检、初始化判断以及二维码、广告和构建流程提示。

### 修复

- 保留构建失败时的真实 Lua/LSP 错误，不再被通用 MCP 错误覆盖。
- 补充 MCP 连接、启动和 Tool/Resource 调用失败的诊断信息。
- 修复项目配置缺失、错位或异常时错误判断和恢复提示不准确的问题。
- 修复已配置屏幕方向的项目重复要求确认的问题。

- 新增线上玩家反馈查询，支持获取真机日志、截图和反馈内容。

### 优化与修复

- 构建流程回到同步路径，移除本地异步构建入口。
- 优化 WorkBuddy 接入配置和只读 trust diagnostics。
- 优化项目初始化、构建以及广告、反馈、提交等 Maker MCP 标准流程指引。
