# 015 画布模拟用户操作测试流程

目的：通过真实界面完成设计稿到可编辑 UI 的交付，检查恢复和素材存储边界。本文是测试步骤，不是已通过的验收记录。

## 准备

- 在已确认的测试项目中新建独立画布，优先使用 Cindy 内置浏览器。保留原画布、用户草稿和已有交付。
- 准备一张含普通文字、美术字、背景及按钮状态的真实设计稿；至少覆盖一次百元素、多批次场景，并补测 JPEG/WebP 输入。
- 确认生图与识图 API 可用；开始前取得本轮付费操作授权。记录项目、版本、画布名称及素材目录初始状态。
- 主流程通过界面点击、输入、预览和保存完成，不用 CLI、脚本或直接修改画布 JSON 代替操作。局部复测复用已有原稿、Bbox 和有效产物。

## 主流程

| 步骤 | 模拟用户操作                                                       | 检查结果                                                                                   |
| ---- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 1    | 进入自由画布，添加 015 模板，再保存、重新打开                      | 内容及时显示，图片可读；添加模板不向游戏 `assets/` 复制示例素材                            |
| 2    | 点击“选择/替换原始设计稿”，换成自己的图片                          | 原图比例、尺寸正确；旧识图和旧交付不冒充新图的有效结果                                     |
| 3    | 点击“开始：自动生成 UI”，观察阶段、卡片和日志                      | 去文字、UI 元素识别及原稿文字识别按依赖执行；状态和实际任务一致                            |
| 4    | 查看识图标注、预排及批次；需要人工检查时使用现有暂停/继续入口      | 元素、文字、背景、美术字和按钮状态未明显漏项；进度与当前执行步骤一致                       |
| 5    | 查看分离结果和切图预览，尝试修改一处裁框并确认                     | 检查透明边缘、空心边框、串槽、裁切及绑定；只处理有问题的批次，已有独立结果保留             |
| 6    | 等待自动组装，或在素材就绪后点击“组装 UI”                          | 输出游戏 PNG、`assembled.ui.json`、参考图及 `.meta`；引用检查无错误，待复核/缺失项如实显示 |
| 7    | 点击“打开 UI 编辑器”，对照原稿查看并修改一处文字或位置，保存后重开 | 打开的是本次 UI；布局、层级、背景和状态正确，普通文字是可编辑 Label，修改仍存在            |
| 8    | 查看“AI 复核修复提示词”，再回到画布                                | 提示词对应本次产物及实际待处理项；不使用 AI 也能打开、编辑和保存 UI                        |

“UI 已生成”只代表产物已生成。存在未复核切图或视觉偏差时，记录具体问题，不写成视觉验收通过。

## 定向复测

以下场景在测试副本中分别验证；仅复测受影响步骤，不默认重跑整套付费流程。

- **失败和重复操作**：遇到超时/未知结果时先查询原任务；重试本地下载不重新生图，同一识图请求不重复提交。刷新、停止再继续后，有效产物仍能复用。
- **修改与删除**：换原稿或重做单批后，相关下游显示过期；只移动卡片不重新生成。运行中删除、撤销测试卡时，无关分支和用户编辑不被覆盖，迟到结果不误接回。
- **切图问题**：失败时原图和已有结果保留，能查看原因并手调；预览后修改来源，旧确认不能继续使用。
- **缓存与离线**：仅在隔离缓存环境验证缺失/损坏，不能清理用户公共缓存。画布仍可打开、编辑和保存；联网后操作所需素材可恢复，无法恢复的素材不能交付。
- **项目目录**：普通图片上传、预排和切图只进入画布工作目录；手动 PNG/JPG 导出到所选位置；015 最后才交付到 `assets/ui/`。Maker MCP 内置生成的原始下载仍按原规则落盘。
- **交付保护**：已有编辑器草稿或已保存的人工修改不得被重新组装覆盖；需要重新交付时生成新版本，旧版本仍可打开。

服务端补充验证：在隔离的空 Maker home 下，不预先打开图片，用已有 CLI 入口读取识图输入、归档或交付，确认自行恢复所需素材。该项单独记录，不能替代上述界面主流程。

## 记录

每次只记录：输入与版本、实际操作、通过/失败/未测、具体问题、最终 UI 位置。耗时只记录整体与每卡耗时；截图集中在关键步骤，临时报告留本地，不随代码提交。

完整协议与恢复规则见 [UI 工作流说明](MAKER_UI_WORKFLOW.md) 和 [示例资源说明](MAKER_DEMO_RESOURCES.md)。
